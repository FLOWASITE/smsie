### Task 2: `internal/simhealth` thuần + service + scheduler hook

- [ ] `evaluate.go`:

```go
type Config struct { NoSMSDays, UnregisteredHours, AbsentDays int }
type Input struct {
	ICCID string; Online bool
	LastRegisteredAt, FirstSeenAt, LastSMSAt, LastRemovedAt *time.Time
	InBay bool
}
type Finding struct { ICCID, Kind, Detail string }
func Evaluate(now time.Time, cfg Config, inputs []Input) []Finding
```
  Quy tắc (spec): 
  - `no_sms`: ref = LastSMSAt nếu có, else FirstSeenAt; ref != nil && now-ref ≥ NoSMSDays ngày → Detail `không nhận SMS nào %d ngày — có thể bị thu hồi`.
  - `unregistered`: Online && (LastRegisteredAt != nil ? now-LastRegisteredAt : FirstSeenAt != nil ? now-FirstSeenAt : 0) ≥ UnregisteredHours giờ → `không đăng ký mạng %d giờ dù modem online`.
  - `absent`: !InBay && LastRemovedAt != nil && now-LastRemovedAt ≥ AbsentDays ngày → `đã rút khỏi khay %d ngày`.
  Test 6 trường hợp theo spec + `absent` không báo khi InBay.
- [ ] `service.go`:

