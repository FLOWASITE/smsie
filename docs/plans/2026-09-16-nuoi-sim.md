# Nuôi SIM (keep-alive) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Định kỳ gửi 1 SMS nội mạng từ SIM bật nuôi sang SIM khác trong khay; nhật ký, trần tháng, cảnh báo; tắt mặc định.

**Architecture:** Package `internal/keepalive`: phần thuần (`pickTarget`, `isDue`) + `Service` (Collect/RunAll/RunOne) với interface `Sender` để test không cần modem; chạy hằng ngày lúc `run_hour` bằng goroutine riêng (`Service.Run(stop)`), KHÔNG dùng `balance.Scheduler` (giờ khác, và không được chạy lúc boot). API 3 endpoint + 2 trường profile. UI thay khối preview "Lịch duy trì".

**Tech Stack / lệnh / commit:** như các đợt trước. Spec: `docs/specs/nuoi-sim.md`. Nhánh `feat/nuoi-sim` từ `main` (đã có slot-history, balance, simhealth).

### Task 2: Service + scheduler + API + profile + main

- [ ] `service.go`:

```go
type Sender interface{ SendSMS(iccid, phone, msg string) error }
type workerSender struct{ wm *worker.Manager } // GetWorkerByICCID → w.SendSMS(phone, msg); nil worker → error "modem offline"
type Service struct { db *gorm.DB; wm *worker.Manager; sender Sender; webhooks *logic.WebhookService; cfg config.KeepaliveConfig; repo *repository.KeepaliveRepository; alerts *repository.SimAlertRepository; mu sync.Mutex; now func() time.Time }
func NewService(db, wm, sender, webhooks, cfg) *Service  // sender nil → workerSender
type Item struct { ICCID, PhoneNumber string; SlotNumber *int; Enabled bool; IntervalDays int; LastActivityAt, NextDueAt *time.Time; SentThisMonth int; LastRun *model.KeepaliveRun; Online bool }
func (s *Service) Collect() ([]Item, error)
func (s *Service) RunAll() (int, error)              // cfg.Enabled false → 0, nil; duyệt Item Enabled && Online; isDue → runOne(item, false); sleep 5s giữa các SIM (select trên stop nếu có)
func (s *Service) RunOne(iccid string, force bool) (*model.KeepaliveRun, error) // cfg.Enabled false → ErrDisabled; force bỏ qua isDue, vẫn trần
func (s *Service) Run(stop <-chan struct{})          // mỗi ngày cfg.RunHour:00 local (nextCheck như balance — copy hàm nhỏ, không import balance)
```
  `runOne`: trần tháng → run `skipped` + alert (AlertedWithin(iccid,"keepalive",30d) để 1 lần/tháng); pick → không có → `skipped` + alert 7 ngày; render message qua `text/template` với `{{.Date}}`; `sender.SendSMS` → `sent` / `failed`+alert. Alert text `🔁 SIM {phone|iccid} (khe N): nuôi SIM thất bại — {reason}`. Tests (sqlite + fake sender ghi lại lời gọi): disabled → sender không gọi; due+đích → sent; sender lỗi → failed + sim_alerts; trần → skipped; not due & !force → không run.
- [ ] `keepalive_handler.go` + test: `Status` (lọc quyền như balance), `Runs` (admin; filter iccid), `RunNow` (admin; body `{iccid?}`; `cfg.Enabled=false` → 409 `{"error":"keepalive.enabled=false trong config.yaml"}`; có iccid → `RunOne(iccid, true)` đồng bộ trả run; không → `go RunAll()` trả 202).
- [ ] `UpdateProfile`: `keepalive_enabled` (bool), `keepalive_interval` (int ≥1 hoặc null) theo cùng cơ chế RawMessage đã có cho `low_balance_vnd`; test.
- [ ] `main.go`: AutoMigrate; `ks := keepalive.NewService(db, wm, nil, webhookSvc, config.AppConfig.Keepalive)`; `go ks.Run(stop)`; routes `authGroup.GET("/keepalive/status")`, `adminGroup.GET("/keepalive/runs")`, `adminGroup.POST("/keepalive/run")`.
- [ ] Commit `feat(keepalive): service gửi SMS nội mạng theo chu kỳ, trần tháng, cảnh báo; API; profile`.
